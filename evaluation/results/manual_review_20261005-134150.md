**Reference:** By prompting a proprietary LM, GPT-4, to produce reflection tokens for input/output pairs.
**System answer:**

The critic’s supervised data were created automatically with a large language model rather than by hand. For each input‑output pair \((x, y)\) in the training set, the authors prompted GPT‑4 to generate a “reflection token” \(r\) that evaluates the pair (e.g., the usefulness of retrieved passages) — this token is then stored as \((x, y, r)\) in the critic’s training set [​S3​]. The authors note that manual annotation of such reflection tokens is costly, so they rely on a state‑of‑the‑art LLM (GPT‑4) to collect them efficiently [​S1​].
